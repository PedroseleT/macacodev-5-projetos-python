# 5. Agora você tem uma base para criar sozinho

Você chegou ao projeto que reúne os principais assuntos da trilha. Não significa
que precisa lembrar cada comando de cabeça. Significa conseguir dividir uma ideia,
procurar o que falta e construir aos poucos.

## Faça uma rodada completa

Cadastre uma oportunidade em Interesse. Depois, informe a data de candidatura
e mude para Candidatura enviada. Avance para Entrevista, faça uma pesquisa,
gere a tabela e feche o programa.

Ao abrir, confira se tudo continua salvo. Exclua uma oportunidade de demonstração
e veja se as outras permaneceram. Você está usando o programa como alguém que
realmente depende dele para se organizar.

## Uma versão sua vale mais que cinco cópias

Escolha uma melhoria que teria utilidade para você. Pode ser um campo de observações
ou uma lista das vagas que estão há muito tempo sem atualização.
Há sugestões em [ideias para continuar](../desafios.md) e pistas nas [ajudas](../dicas.md).

Antes de mudar, escreva o comportamento desejado. Depois faça uma função pequena,
rode o programa e acompanhe o resultado.

Quando quiser compartilhar, explique o que veio da base MacacoDev e o que você
modificou. Não publique dados reais de candidaturas, contatos ou mensagens
de recrutadores.

Confira [o que já aprendeu](../checklist.md). Publicar é opcional neste momento;
o [guia de Git e GitHub](../../COMO-USAR-GIT-E-GITHUB.md) fica disponível para
quando você quiser dar esse próximo passo.

A próxima ideia pode ser sua: escolha um pequeno problema do dia a dia e repita
o caminho que praticamos aqui.
