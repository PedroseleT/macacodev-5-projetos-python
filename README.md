# 🐒 MacacoDev | 5 Projetos Python para Sair do Tutorial

**Já assistiu às aulas, mas trava quando precisa criar algo sozinho? Bora construir.**

Aqui você vai fazer cinco programas em Python, começando com algo pequeno e
adicionando uma coisa de cada vez. Tem explicação, espaço pra tentar e uma ajuda
quando bater aquela dúvida. Você não precisa saber tudo antes de começar.

## Primeira vez no GitHub? Começa aqui

O GitHub é o site onde guardamos os arquivos do projeto. Pode deixar a lista de
pastas lá de cima pra depois: **seu ponto de partida é o botão abaixo.**

### [Começar do zero: baixar os arquivos e preparar o computador →](COMECE-AQUI.md)

Não precisa instalar Git nem criar conta no GitHub para acompanhar.
Você pode ler pelo celular; para escrever e executar os programas, use um computador.

## O que a gente vai construir?

Siga nessa ordem. Cada projeto aproveita um pouco do que você fez no anterior.

| Projeto | O que você vai fazer | Dificuldade |
|---|---|---|
| [1. Desperdício Zero](01-desperdicio-zero/README.md) | Lembrar quais alimentos estão perto de vencer | Primeiro projeto |
| [2. BuscaCEP](02-buscacep/README.md) | Digitar um CEP e descobrir o endereço | Um passo além |
| [3. OrçaDev](03-orcadev/README.md) | Montar um orçamento de serviços | Juntando as peças |
| [4. Fila Justa](04-fila-justa/README.md) | Organizar senhas de atendimento | Juntando as peças |
| [5. Radar de Vagas](05-radar-de-vagas/README.md) | Acompanhar suas candidaturas de emprego | Desafio final |

Em cada projeto, você vai entender a ideia, pensar no que precisa fazer, escrever
por partes e aprender a resolver os problemas que aparecerem. Se travar, tem dicas.
A versão pronta também está disponível para comparar depois da sua tentativa.

## Qual pasta eu abro?

Dentro de cada projeto, o arquivo `README.md` é a página de apresentação,
igual a esta. Ele mostra qual é o próximo passo. Você não precisa abrir todos
os arquivos nem entender a organização inteira de uma vez.

- `passo-a-passo`: as explicações, em ordem. É por aqui que você estuda.
- `codigo-inicial`: os arquivos que você vai usar para começar a escrever.
- `solucao`: uma versão pronta para consultar quando precisar comparar.

As outras pastas podem esperar. Primeiro, vamos fazer o primeiro programa sair do papel.

## Sem pressa, mas com a mão no código

Você conhece o básico de variáveis, `if` e repetição? Já pode tentar. Se alguma
parte estiver enferrujada, a gente explica quando ela aparecer.

Não tem prazo para terminar. O importante é conseguir dizer o que você fez e por
que funcionou. Não precisa sair daqui com cinco cópias: uma versão que você
entendeu e adaptou já tem valor.
