# O que você já consegue fazer?

Não precisa decorar tudo. O importante é entender suas próprias decisões.

- [ ] Cadastro um cliente de demonstração.
- [ ] Coloco mais de um serviço no orçamento.
- [ ] Entendo quantidade vezes preço e a soma do subtotal.
- [ ] Uso Decimal a partir de texto para calcular dinheiro.
- [ ] Não aceito quantidade zero nem preço negativo.
- [ ] O desconto não deixa o total negativo.
- [ ] Mostro cliente, serviços, desconto e total de forma clara.
- [ ] Fecho e abro o programa sem perder as propostas.
- [ ] Consigo gerar novamente o texto de um orçamento salvo.
- [ ] Sei que este programa não emite nota fiscal.
- [ ] Consigo explicar uma função sem ler cada linha.

Se a conta ainda parecer confusa, volte a um único serviço e faça o cálculo
no papel. Um exemplo pequeno já ajuda a encontrar o ponto que faltou entender.
