# O que já ficou mais claro?

Use estas perguntas para revisar sem precisar decorar os nomes técnicos.

- [ ] Explico API como uma forma de programas trocarem informações.
- [ ] Aceito CEP com e sem hífen, sem perder o zero inicial.
- [ ] Um CEP incompleto recebe uma mensagem antes de usar a internet.
- [ ] Mostro rua, bairro, cidade e estado quando disponíveis.
- [ ] Diferencio CEP não encontrado de falha na conexão.
- [ ] A pessoa consegue tentar outra consulta depois de um problema.
- [ ] Só consultas válidas entram no histórico.
- [ ] Fecho, abro e consigo ver o histórico sem consultar a internet.
- [ ] Uso endereço público de exemplo, não o da minha casa.
- [ ] Consigo explicar uma mudança que fiz por conta própria.

Se faltou alguma parte, volte a ela. Não precisa terminar todos os desafios
para seguir a trilha.
