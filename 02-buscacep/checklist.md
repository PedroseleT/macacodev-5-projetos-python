# Checklist

- [ ] Explico API, requisição, resposta HTTP e JSON com um exemplo.
- [ ] Preservo zeros e rejeito CEP inválido antes da rede.
- [ ] Distingo CEP inexistente de servidor indisponível.
- [ ] Trato timeout, JSON inválido e campos ausentes.
- [ ] Permito tentar novamente após erro.
- [ ] Somente respostas válidas entram no histórico.
- [ ] Histórico funciona após reiniciar e sem internet.
- [ ] Executei os testes offline e entendi a simulação.
- [ ] Não publiquei endereços pessoais.
