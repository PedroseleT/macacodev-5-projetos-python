# Identidade visual

A identidade desta versão é tipográfica: título, uma referência discreta ao macaco,
tabelas e demonstrações de terminal. Não há imagens de terceiros ou fontes externas
embutidas. A organização padronizada dos cinco projetos prioriza leitura no celular
e leitores de tela. Imagens futuras deverão ter autoria/licença registrada aqui e
texto alternativo; elas não podem substituir instruções textuais.
